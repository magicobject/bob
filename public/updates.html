Site updates

An internal changelog: every build number and what changed. This page isn't linked from anywhere else on the site.

  • 2026.09.17.002Greg Wright17 September 2026

    The DNA high-performance air filter added to the upgrades list — now ten upgrades, not nine — actually landed in the previous build (.001) rather than this one: scripts/bump-build-number.mjs used to run git add on every page unconditionally, which swept that still-unstaged edit into a commit whose message only mentioned the favicon. It now only patches and stages a page's footer if that page is already staged for the commit being made, so this can't happen again — see CLAUDE.md.

  • 2026.09.17.001Greg Wright17 September 2026

    Redrew the favicon as a proper side-on motorbike silhouette — two wheels, tank, seat, engine block, forks and a headlamp — instead of the original abstract wheels-and-handlebar mark, which read more like a bicycle.

  • 2026.09.16.001Greg Wright16 September 2026

    Added build-number versioning and this changelog page, matching kington-parishes' convention: a pre-commit hook bumps build-number.json and stamps the new number into the listing and 404 page footers, and every commit from here on gets tagged build-YYYY.MM.DD.NNN and logged here.
