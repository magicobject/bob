Site updates

An internal changelog: every build number and what changed. This page isn't linked from anywhere else on the site.

  • 2026.09.26.004Greg Wright26 September 2026

    Added a section menu to the listing, directly below the header bar — Meet Bob, The upgrades, Photos, Maintenance history and Interested in Bob? — each jumping straight to that section, styled to match the header and wrapping onto two lines on narrow screens.

  • 2026.09.26.002Greg Wright26 September 2026

    Gave the copy on the listing a lighter, more humorous tone — hero lede, "Meet Bob" text, upgrade card descriptions, photos intro and the contact/price wording. All factual details (price, mileage, dates, spec names, contact details, maintenance history table and JSON-LD) are unchanged.

  • 2026.09.26.001Greg Wright26 September 2026

    Test suite fixes, no visible change to the listing. The price test now reads the price from the page's JSON-LD instead of hardcoding it (it was still expecting £4450 after the change to £4500). A new .gitattributes forces LF line endings on checkout, so the JSON-LD CSP hash computed on a Windows machine matches the deployed one. scripts/update-csp-hash.mjs now actually runs on Windows too — its run-directly check never matched a Windows path, so the pre-commit hook and npm run build silently skipped it there. Added type declarations for it so npm run typecheck passes again.

  • 2026.09.25.002Greg Wright25 September 2026

    The JSON-LD script's CSP hash in public/_headers is no longer hand-recomputed — scripts/update-csp-hash.mjs derives it from the actual script content, wired into the pre-commit hook, a new npm run build step (for the Cloudflare Pages build command), and a new test (test/csp-hash.spec.ts) that holds an out-of-sync hash for review instead of letting it reach production. Prompted by the volunteer-edit pipeline now being able to change the listing price without a human recomputing the hash by hand. Also fixed .githooks/pre-commit and .githooks/pre-push never having been committed executable, which meant this automation (and every prior build-number bump) never actually ran via git itself.

  • 2026.09.25.001Greg Wright25 September 2026

    Backend-only change: the site-editor pipeline's safety check now correctly ignores this page's own <script type="application/ld+json"> structured-data block (search-engine listing info, never executed by a browser) instead of treating it as a suspicious script every time it's touched.

  • 2026.09.24.003Greg Wright24 September 2026

    Changed the asking price on the listing from £4500 to £4450 everywhere it appears — title, meta/social descriptions, header, hero, spec list, sale text, price banner and the JSON-LD offer — and recomputed the JSON-LD script's CSP hash to match.

  • 2026.09.17.002Greg Wright17 September 2026

It now only patches and stages a page's footer if that page is already staged for the commit being made, so this can't happen again — see CLAUDE.md.
